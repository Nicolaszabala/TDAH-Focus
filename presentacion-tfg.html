Base Neurobiológica del TDAH

🧬 Déficit de Dopamina

  • Neurotransmisor clave en motivación y recompensa
  • Niveles reducidos en corteza prefrontal
  • Afecta la capacidad de iniciar acciones
  • Dificulta mantener el foco en tareas

🧠 Disfunción Ejecutiva

  • Planificación deficiente
  • Dificultad con memoria de trabajo
  • Problemas de inhibición de impulsos
  • Flexibilidad cognitiva reducida

💡 Implicación para el Diseño

Las intervenciones deben proporcionar estructura externa, recompensas frecuentes y reducción de carga cognitiva para compensar estas dificultades neurobiológicas.

Cálculo de Progreso

updateGoalProgress: (state, action) => {
  const { goalId, completedTaskIds } = action.payload;
  const goal = state.goals.find(g => g.id === goalId);

  goal.completedTasks = goal.taskIds.filter(
    id => completedTaskIds.includes(id)
  ).length;

  goal.progressPercentage = Math.round(
    (goal.completedTasks / goal.totalTasks) * 100
  );

  // Auto-completar si 100%
  if (goal.progressPercentage === 100) {
    goal.status = 'completed';
  }
}

Asistente IA: Especialización TDAH

Detección de Patrones

const PATTERNS = {
  PARALYSIS:
    /no sé (por dónde|qué) empezar/i,
  FOCUS_LOSS:
    /distraído|perdí (el )?foco/i,
  INDECISION:
    /qué (hago|tarea)|cuál priorizo/i,
  MOTIVATION:
    /sin ganas|desmotivado/i
};

function detectPattern(message) {
  for (const [name, regex]
       of Object.entries(PATTERNS)) {
    if (regex.test(message))
      return name;
  }
  return null;
}
